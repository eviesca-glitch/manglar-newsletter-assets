# Manglar Newsletter Assets

Permanent image hosting for Manglar Capital investor newsletters.
These URLs never expire — paste them straight into the email HTML.

## Structure
One folder per closing. Add a new folder each quarter.

    /heritage/hero.jpg      property hero photo
    /heritage/lockup.png    Manglar | Invertikal partnership lockup
    /heritage/mark.png      Manglar footer monogram

## URL pattern (GitHub raw — works in email, permanent)
    https://raw.githubusercontent.com/<user>/manglar-newsletter-assets/main/heritage/<file>
